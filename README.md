# norglyph.com

Coming-soon site for Norglyph: a printed-atlas globe, a read-only index of work, and an About and Contact page.

- `index.html` is the whole site (one self-contained file).
- Hosted on Netlify; every push to `main` deploys automatically.
- The enquiry form uses Netlify Forms (`name="enquiry"`).
- Fonts: Neue Haas Grotesk via Adobe Fonts (kit `cum7lbw`), IBM Plex Mono via Google Fonts.
